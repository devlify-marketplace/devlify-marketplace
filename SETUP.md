# Setup (5 minutes)

1. Put everything in this folder in your profile repository (`devlify-marketplace/devlify-marketplace`), keeping the `.github` folder, `assets` folder and `README.md` together. Commit and push to `main`.
2. In the repo go to **Settings, Actions, General, Workflow permissions** and choose **Read and write permissions**.
3. Open the **Actions** tab and run **Update profile** once, then **Contribution snake** once. After a minute your stats, language chart, recent repositories and snake appear. They refresh every 12 hours after that.
4. Optional: to count private contributions, create a classic personal access token with `read:user` and `repo` scopes and save it as a repository secret named `PROFILE_TOKEN`.
5. Set your GitHub bio from `BIO.txt`.

Light mode: every graphic ships with a `-light.svg` variant that GitHub shows automatically to visitors using the light theme.
